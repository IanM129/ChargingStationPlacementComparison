- Albert Y.S.; Electric Vehicle Charging Station Placement: Formulation, Complexity, and Solutions:
undirected graph with a set of possible construction sites
construction sites are connected by edges where distance = road distance
D = average distance to be traversed by most typical EV models when fully charged
definition of reachable by D
Ci is construction cost
minimize sum(Ci * Xi) (Xi is 0 or 1)
Greedy algorithm:
	N is all candidate nodes
	repeat:
		select node X with most cost and remove it from the graph
		if the resulting graph is fully connected:
			continue (the node stays removed from the graph)
		else:
			return X to graph and remove it from N 
	until N is empty
	--> the algorithm removes each of the nodes only when removing the node keeps the graph fully connected, otherwise it removes it from N, and so on until it finds a suboptimal solution of N nodes which are the selected stations
MILP:
	formulates a Mixed-Integer Linear Program problem where each Xi is 0 (not selected)
	concludes that the problem is solvable through MILP methods (like branch-and-bound) if one of the Xi is 1
	no trivial way to choose the starting Xi = 1 -> solve it for each possible starting Xi = 1

- Bae, S.; A Game Approach for Charging Station Placement Based on User Preferences and Crowdedness
[EVU = EV user; EVCS = EV charging station]
minimizing installation costs, but also user perspective; considers crowdedness and individual preferences
decentralized game theoretical decision-making algorithm + k-means clustering -> k-GRAPE (GRoup Agent Partitioning and Placing Event) (Stackelberg-style game):
	1. solve the decision-making problem of the EVUs modeled as "hedonic games" -> find a Nash stable partition that is agreed by all EVUs
	-> EVUs form groups to improve own interest; conflict situation; each user considers the "crowdedness" of the group
	-> each selfish user is willing to join a group based on the population density of the EVCS + individual preferences like brand and local attractions and crowdedness
	2. find optimal locations that minimize the social costs generated by EVUs given a Nash stable partition
	-> minimizes the variance of the travel distance between the EVUs and EVCS selected
location of each EVCS is determined without any restrictions
analytically presented that 50% of suboptimality of the solution can be at least guaranteed (17% better than then latest game theory paper)
Overall factors:
	1. User preferences - travel distance, utility or satisfaction, behaviour choice among multiple available stations
	2. Crowdedness (congestion) - expected or real-time, limited capacity
	3. System level utility - globally well distributed locations; overall network performance
	4. Strategic interaction - users act strategically -> Nash equilibrium
solved by an iterative algorithm:
	1. solve user equilibrium (given station locations)
	2. update station placement strategy
	-> heuristic/problem relaxation methods
each time the algorithm tests a set of k locations:
	1. run the GRAPE equilibrium model
	2. compute how the users would distribute themselves (incl congestion)
	3. evaluate system performance
	4. search for best placement configuration
